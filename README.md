💳 SmartBank – Simple Banking Application

SmartBank is a simple banking simulation web application built using HTML, CSS, and JavaScript.
The application allows users to check their current balance, deposit money, withdraw funds, and calculate interest in an interactive interface.

This project demonstrates basic financial transaction logic and front-end development skills.

🚀 Features

💰 View Current Balance – Displays the user’s account balance.

➕ Deposit Money – Add funds to the account.

➖ Withdraw Money – Withdraw funds from the account balance.

📈 Interest Calculation – Automatically calculates interest based on the balance.

⚡ Instant Updates – Balance updates dynamically without refreshing the page.

🎨 Clean User Interface – Simple and responsive UI.

🛠️ Tech Stack

This project is built using:

HTML5 – Structure of the application

CSS3 – Styling and layout

JavaScript (Vanilla JS) – Logic and dynamic behavior

⚙️ How It Works

The application starts with an initial account balance.

Users can perform the following operations:

Deposit money into the account.

Withdraw money from the account.

After each transaction:

The balance is updated instantly.

The system calculates interest automatically.

All calculations happen in the browser using JavaScript.
